## breaking
- [network] 0.2.x nodes, orchestrators and configs incompatible; migrate: new hub via `Настроить reverse proxy и Nexus-машину…`, then add and install every machine from the client
- [release] release repo `Nexus-Releases` -> `Nexus2-Releases`; 0.2.x never self-updates to 0.3; migrate: download 0.3 from `Nexus2-Releases`
- [identity] `nexus-*` -> `nexus2-*`: binaries, services (`nexus2-node`, `nexus2-frpc`, `nexus2-frps`, `nexus2-gate`, `nexus2-hub`), `/etc/nexus2`, `/var/lib/nexus2-node`, `%ProgramData%\nexus2-node`, `.deb` names; v1 and v2 run side by side on one machine

- [orch] client data `~/.config/nexus-orchestrator` -> `~/.config/nexus2-orchestrator`; holds hub code + client key only
## added
- [hub] Nexus machine: `nexus2-node hub` service on the relay, reachable only through frps (stcp `hub`); network state in `hub.bin` (ChaCha20-Poly1305, key `hub.key`), password as Argon2id hash
- [hub] `nexus2-node hub-init` (password on stdin, prints hub code), `install-hub`
- [orch] thin client: login with hub code (`nexus2-hub:...`) + password; Get/Put with revision conflict; set password; copy hub code
- [orch] first setup: relay (frps + gate + frpc) and hub in one job over the single direct SSH connection
- [graph] project graph Dev -> project -> Operative; separate machine links and project links (sync arrow, exec arrow)
- [project] Dev registers a project (`nx2 project add`); Operative folder `<projects_dir>/<name>`, clash -> `<name>-<dev>`
- [sync] Dev-declared sync patterns (G9) via `nx2 sync set|reset`, confined to the project root; per-Operative overrides
- [worktree] sync of all project worktrees to `<worktrees_dir>/<folder>/<name>`; worktree `.git` not synced; `nx2 worktree add|rm`; `nx2 worktree copy` of project paths into a worktree on the Operative
- [agents] agents folder `<agents_dir>/<folder>` on the exec Operative, outside sync; spawned commands get `NX_OUT`, `TMP`, `TEMP`, `TMPDIR` set to it
- [agents] `## Nexus` block in AGENTS.md/CLAUDE.md written automatically
- [wants] `nx2 want program` recorded on the hub, shown in the client
- [harden] v2 files only (`jail.d/90-nexus2.conf`, `sshd_config.d/90-nexus2.conf`, `sysctl.d/90-nexus2-hardening.conf`); fail2ban `ignoreip` merged with existing jails
